#  Designing a Searching Agent


## Project Overview

This repository contains our group's work for Practical Exercise 3, which focuses on designing a self-driving trailer as an intelligent agent and exploring how search algorithms can be applied to route planning.

The scenario involves a self-driving trailer travelling from **Nairobi to Kisumu** through Kenya's highway network. The aim is to represent the road network as a search problem and determine the shortest route using road distances as the path cost.
